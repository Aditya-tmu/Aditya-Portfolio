## 🌌 Overview
Welcome to the official repository of **AK-OS: Itachi Uchiha Edition**, a high-end, immersive developer portfolio engineered for **Aditya Kumar**. Drawing inspiration from the legendary Shinobi Itachi Uchiha, this portfolio intertwines deep obsidian aesthetics, blood-red Sharingan visual effects, 3D flocking crows (Karasu Bunshin), and an interactive Tsukuyomi Genjutsu reality distortion mode with production-grade software engineering showcase.

> *"We do not know what kind of people we truly are until the moment before our deaths."* — **Itachi Uchiha**

## 🛠️ Shinobi Tech Stack
- **Frontend Engine**: Pure HTML5, Modern CSS3 (Obsidian Glassmorphism & 3D Tilt)
- **3D Visual Effects**: [Three.js](https://threejs.org/)
  - Interactive 3D Blood Moon (Tsukuyomi Moon) with procedural Mangekyou Sharingan iris
  - Flock of 30+ 3D Crows (Karasu) with animated flapping wings & interactive flocking physics
  - Ember chakra & black feather particle field with mouse-tracking parallax & scroll depth
- **Genjutsu Trigger**: In-browser Tsukuyomi reality distortion with chromatic aberration & crow burst
- **Data Uplink**: GitHub REST API live repository synchronization
- **Comms Protocol**: EmailJS integration & WhatsApp direct dispatch
- **CLI Interface**: In-Browser Shinobi Terminal (`~` or `Ctrl + K`)

## 📡 Featured S-Rank Missions
- **Vindywashini Books**: Modern Desktop Accounting, Billing, and GST Filing Software for Indian MSMEs ([Live App](https://vindywashini-books.vercel.app/) · [GitHub](https://github.com/Aditya-tmu/Vindywashini-Books))
